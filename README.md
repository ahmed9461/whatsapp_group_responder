# WhatsApp Group Responder — Android App

تطبيق Android شخصي مبني بـ Flutter لإدارة مشروع **WhatsApp Group Responder** عبر REST API v1.

## المرحلة الأولى

- ربط الجهاز عبر API ثم الموافقة من Telegram.
- حفظ Access/Refresh tokens في Secure Storage.
- تجديد جلسة API تلقائيًا.
- لوحة رئيسية.
- إدارة الردود والمجموعات والموافقات والإحصائيات.
- حالة WhatsApp والإعدادات.
- قسم محادثة DeepSeek مستقل بدون System Prompt داخلي.
- Streaming لإجابات DeepSeek.
- نسخ سريع واستخدام إجابة AI كنص رد بعد اختيار الرد والتأكيد.
- تخزين محادثات AI محليًا في SQLite.
- SSE للأحداث الحية.
- RTL عربي وMaterial 3.

## الجديد في الإصدار 0.3.0

- بطاقة خاصة بالمالك في الإعدادات لكتابة رسالة الرد التلقائي لمحادثات الرقم الرئيسي.
- يمكن حفظ النص ثم تشغيله أو إيقافه بشكل مستقل.
- لا يسمح التطبيق بالتشغيل قبل وجود رسالة محفوظة.
- يوضح التطبيق أن النظام يرسل مرة واحدة فقط لكل شخص خلال 12 ساعة.
- بعد تعديل الإعداد يُحدّث قسم الإعدادات فقط بدل تحميل كل بيانات التطبيق.

الرقم الحالي يبقى الرقم الرئيسي الوحيد. ربط رقم WhatsApp مستقل لكل مستخدم غير موجود في هذه النسخة، لأن ذلك يحتاج نظام حسابات وجلسات معزولة بالكامل في الخادم.

## تحسينات الإصدار 0.2.1 المحفوظة

- أحداث SSE تحدّث المورد الذي تغيّر فقط بدل إعادة تحميل جميع الأقسام.
- لا يوجد Polling كامل كل 30 ثانية أثناء اتصال SSE السليم؛ الاستعلام الدوري مسار تعافٍ فقط عند انقطاعه.
- إيقاف SSE والمؤقتات عندما يكون التطبيق في الخلفية، ثم مصالحة كاملة واحدة عند العودة.
- إعادة اتصال بتدرج أسي محدود بدل حلقة ثابتة، مع دمج الأحداث المتقاربة ومنع التحديثات المتداخلة.
- رفع الملفات كتيار من التخزين بدل قراءتها كاملة في ذاكرة الهاتف، مع إمكان إعادة فتح التيار مرة واحدة بعد تجديد الجلسة.
- لا يُعاد بناء `MaterialApp` لكل تحديث بيانات؛ يتغير الغلاف فقط عند تبدل الارتباط أو الثيم.

## التشغيل محليًا

```bash
flutter pub get
bash tool/bootstrap_android.sh
flutter run
```

`bootstrap_android.sh` ينشئ منصة Android باستخدام Flutter Stable المثبت محليًا بدل تثبيت ملفات Gradle قديمة داخل المستودع.

## GitHub Actions

Workflow في `.github/workflows/android.yml` يشغّل التحليل والاختبارات ويبني ARM64 Release APK موقّعًا بهوية المشروع الثابتة ويرفعه كـ artifact.

## DeepSeek

لا يوجد System Prompt مخفي. التطبيق يرسل فقط رسائل `user` و`assistant` الموجودة في المحادثة.

النماذج:
- `deepseek-v4-pro`
- `deepseek-v4-flash`
