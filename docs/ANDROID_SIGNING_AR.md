# توقيع تطبيق Android

يستخدم هذا المشروع هوية توقيع ثابتة للنسخة الشخصية من تطبيق Android حتى يمكن تثبيت الإصدارات الجديدة كتحديث فوق الإصدارات السابقة.

- ملف التوقيع مخصص لهذا التطبيق الشخصي فقط.
- لا يجب استبداله أو حذفه بعد اعتماد v0.1.1، لأن Android يعتمد هوية التوقيع عند التحديث.
- GitHub Actions ينسخ الهوية الثابتة إلى مسار توقيع Android قبل بناء نسخة ARM64 Release.
- هذه الهوية ليست مخصصة للنشر على Google Play أو لتطبيق عام.

## ملاحظة انتقال v0.1.0 → v0.1.1

نسخة v0.1.0 التجريبية بُنيت بهوية Debug مؤقتة من GitHub Runner، لذلك يلزم حذف v0.1.0 مرة واحدة قبل تثبيت v0.1.1 ذات الهوية الثابتة. بعد ذلك يجب أن تُثبت الإصدارات اللاحقة كتحديثات عادية دون حذف التطبيق.
